# Master Prompt untuk IDE Agentic AI

Saya ingin kamu membangun prototype UI aplikasi Flutter bernama **TugasKu**.

Baca dan ikuti file berikut:

- `PROJECT_BRIEF.md`
- `REQUIREMENTS.md`
- `UI_SCREENS.md`
- `DATA_DUMMY.md`
- `CODING_RULES.md`
- `TASKS.md`

## Scope Proyek

- Fokus hanya pada tampilan UI dan navigasi.
- Tidak menggunakan database.
- Tidak menggunakan Firebase.
- Tidak menggunakan API.
- Data menggunakan dummy data lokal.
- Jangan membuat fitur di luar requirements.
- Ikuti struktur folder yang sudah ditentukan.
- Kerjakan berdasarkan `TASKS.md` secara bertahap.

## Instruksi Kerja

Mulai dari Task 1.

Setelah selesai satu task, jelaskan:

1. File apa saja yang dibuat.
2. File apa saja yang diubah.
3. Ringkasan perubahan.
4. Apakah ada error atau dependency tambahan.

Jangan lanjut ke task berikutnya sebelum task sebelumnya selesai dengan benar.

## Batasan Penting

Jangan membuat:

- Database SQLite.
- Firebase.
- API.
- Login asli.
- CRUD permanen.
- State management kompleks.

Gunakan `StatefulWidget`, `StatelessWidget`, dummy data, dan navigasi bawaan Flutter saja.
