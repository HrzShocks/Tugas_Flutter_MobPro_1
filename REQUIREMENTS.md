# Requirements

## Fitur Wajib

1. Splash Screen.
2. Login Screen dummy.
3. Dashboard Screen.
4. Task List Screen.
5. Task Detail Screen.
6. Task Form Screen.
7. Subject Screen.
8. History Screen.
9. Profile Screen.
10. Bottom Navigation.

## Fitur Tampilan yang Harus Ada

- Card ringkasan tugas.
- Card daftar tugas.
- Search bar dummy.
- Filter chip dummy.
- Form input tugas.
- Dropdown mata kuliah.
- Dropdown status.
- Dropdown prioritas.
- FloatingActionButton untuk tambah tugas.
- SnackBar simulasi ketika tombol simpan ditekan.

## Fitur Tidak Dibuat

- Database SQLite.
- Firebase.
- REST API.
- Login autentikasi asli.
- CRUD permanen.
- Upload file.
- Push notification.
- Sistem autentikasi admin.

## Behavior Aplikasi

- Tombol login langsung mengarah ke Main Screen tanpa validasi database.
- Terdapat simulasi pilihan role (Dosen / Mahasiswa) saat login.
- Tombol simpan pada form hanya menampilkan SnackBar.
- Tombol edit dan tandai selesai boleh berupa simulasi tampilan.
- Semua data berasal dari file dummy data lokal.
