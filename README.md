# TugasKu Agent Brief

Paket ini berisi dokumen instruksi untuk membangun prototype UI aplikasi Flutter bernama **TugasKu**.

Project ini ditujukan untuk mata kuliah **Mobile Programming 1**, sehingga fokusnya hanya pada tampilan UI dan navigasi, bukan database atau backend.

## Isi Paket

- `PROJECT_BRIEF.md` - Gambaran umum proyek.
- `REQUIREMENTS.md` - Daftar fitur dan batasan sistem.
- `UI_SCREENS.md` - Detail tampilan setiap halaman.
- `DATA_DUMMY.md` - Data dummy untuk aplikasi.
- `CODING_RULES.md` - Aturan coding dan struktur folder.
- `TASKS.md` - Urutan pekerjaan untuk agentic AI.
- `MASTER_PROMPT.md` - Prompt utama untuk diberikan ke IDE agentic AI.

## Cara Pakai

1. Buat project Flutter baru.
2. Salin semua file `.md` ini ke root project Flutter.
3. Buka project di IDE agentic AI seperti Cursor, Windsurf, Trae, Cline, atau sejenisnya.
4. Berikan isi `MASTER_PROMPT.md` ke agent.
5. Minta agent mengerjakan task satu per satu berdasarkan `TASKS.md`.

## Catatan

Jangan minta agent langsung membuat fitur penuh. Project ini hanya prototype UI untuk Mobpro 1.
