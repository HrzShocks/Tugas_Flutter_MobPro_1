# Project Brief

## Nama Aplikasi

**TugasKu**

## Jenis Aplikasi

Prototype UI aplikasi sistem informasi tugas kuliah berbasis mobile menggunakan Flutter.

## Tujuan

Membuat tampilan aplikasi mobile yang membantu mahasiswa melihat, mencatat, dan memantau tugas kuliah secara sederhana dan terstruktur.

## Scope Proyek

Proyek ini dibuat untuk mata kuliah **Mobile Programming 1**, sehingga fokus utama hanya pada:

- Tampilan UI aplikasi.
- Navigasi antar halaman.
- Penggunaan dummy data lokal.
- Struktur folder Flutter yang rapi.
- Komponen UI reusable.
- Multi-role user (Dosen dan Mahasiswa).

## Hal yang Tidak Dibuat pada Tahap Ini

- Database SQLite.
- Firebase.
- REST API.
- Login autentikasi asli.
- CRUD permanen.
- Upload file.
- Push notification.
- Autentikasi admin.

## Target Pengguna

Dosen yang dapat memberikan tugas dan Mahasiswa yang dapat melihat serta mengumpulkan tugas melalui aplikasi mobile.

## Platform

Android mobile app menggunakan Flutter.

## Catatan Penting

Aplikasi ini adalah prototype UI. Data tugas masih menggunakan dummy data dan belum tersimpan secara permanen.
